# Roblox Advanced

*Data, scale and a game that stays up*

---

A game that works in one server can still lose data, duplicate items, charge twice or fall over at scale. This course covers what happens past one server: DataStores that survive throttling and crashes, session locking so a player's data has one owner, migrations and leaderboards, MessagingService and MemoryStore across servers, developer products that never grant twice, teleports that carry data safely, instance streaming, Parallel Luau and profiling, and the security, moderation and live updates a running game needs. You build a hub: first its profile store, then the lobby around it. The Scribe course teaches a production library that handles sessions for you; this course teaches the mechanics it is built on.
