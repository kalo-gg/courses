# LuauX

*JSX for Luau*

---

LuauX compiles `.luaux` files — JSX-style markup — into plain Luau that calls React, Vide, Fusion or Fluid, and ships nothing to the game. This course covers the syntax and the one place reactivity is implicit, components, how the same markup lowers to four libraries, the compiler, the larvae worm that formats and lints markup files and the editor extension that types them, and the patterns that keep a screen debuggable. Across two projects you build a **settings screen** — toggles, a keybind list and a confirm dialog — first for Vide, then wired into Rojo and ported to a second backend.
