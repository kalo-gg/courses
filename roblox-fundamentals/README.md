# Roblox Fundamentals

*The engine under every Roblox game*

---

Every Roblox game is a tree of instances, and every script changes that tree. This course teaches the engine from the server side: the DataModel and its services, where scripts run, how to create, find and destroy instances, the events that tell you when something happens, and the players and characters who join. Then it covers Vector3 and CFrame math, and motion: the frame loop, tweens, physics and constraints. It ends with how to organise, debug and clean up a place so a server can run for days. You build an obby: hazards and checkpoints first, then the whole game.
