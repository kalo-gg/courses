# 1. Fluid Foundations

*A declarative UI library that grew out of Vide — same spine, different opinions.*

Fluid · Easy

---

Fluid describes interfaces as functions of state, the way Vide does, then rewrites the details on purpose. This module covers what Fluid is, how to pin a release candidate honestly, the stable scope that everything reactive needs and the two errors you get without one, and the single mixed table `create` takes for properties and children alike.

## Lessons

1. [What is Fluid?](01-what-is-fluid.md) — Declarative UI for Roblox, built on a push-pull reactive graph that started life as Vide.
2. [Installing Fluid](02-installing-fluid.md) — One Wally line, an exact pin, and an honest look at what a release candidate means.
3. [Sources and scopes](03-sources-and-scopes.md) — State is a function you call, and almost everything else needs a scope to live in.
4. [Creating instances](04-create.md) — One mixed table holds the properties and the children, and Fluid sets no defaults of its own.
