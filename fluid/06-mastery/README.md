# 6. Mastery & Migration

*Porting a Vide screen, paying for reactivity knowingly, and shipping on a release candidate.*

Fluid · Hard

---

The last module is about decisions rather than calls: what a Vide app has to change to become a Fluid app, what each kind of node costs and where the deferred phase saves you, how to live with a library whose 0.7 line has never been tagged, and how to lay a screen out before writing it. Then you build the round-end screen.

## Lessons

1. [Porting a Vide screen](01-from-vide.md) — What a Vide screen must change to become a Fluid screen, and what breaks without a word.
2. [What reactivity costs](02-performance.md) — What each kind of node costs, and where the deferred phase does the saving for you.
3. [Shipping on a release candidate](03-pre-1-0.md) — Living with a library whose 0.7 line has never been tagged, and the toolchain around it.
4. [Structuring a screen](04-structuring-a-screen.md) — Lay a Fluid screen out before you write it, and plan the one you are about to build.
