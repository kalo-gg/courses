# Fluid

*Declarative UI, rewritten from Vide*

---

Fluid is a declarative UI library for Roblox that started, in its README's words, as "a series of W.I.P. pull requests to Vide" and ended up a full opinionated rewrite. This course covers the reactive graph, the stable scopes everything lives in, instances built from one mixed table of properties and children, lists whose entries know when they are leaving, and animation that hands you a control function alongside the value. You build one thing across it: **the round-end screen** of a round-based game — a scoreboard whose rows fade out as players drop, a profile that arrives late, a countdown on a clock, and a panel that springs in from off-screen.
