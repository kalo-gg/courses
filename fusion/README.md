# Fusion

*Reactive UI for Roblox*

---

Fusion is a Luau companion library for building interfaces out of state objects instead of updating instances by hand. This course teaches the 0.3 release: scopes and the cleanup they own, values and the computeds derived from them, observers for side effects, instances built with New and Hydrate, lists that follow their data with ForValues, animation with tweens and springs, and the components and lifetimes that make a screen shippable. Two projects build one thing, an in-game shop: a panel after the instances module, the whole screen at the end. Every lesson runs against the real Fusion 0.3 sources in your browser.
