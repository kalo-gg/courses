# Rojo

*File sync for Roblox Studio*

---

Rojo maps a folder of files onto Roblox instances: a project file says where each directory lands in the game, file names decide which class each file becomes, and a Studio plugin keeps the place in sync while you edit. Six modules take you from installing Rojo and reading a project file, through every sync rule and project-file setting, to the day-to-day loop of serve, build and editor tooling, then Wally packages, syncback and CI, and finally the structure of a real repository with several places, a library and its tests. Two projects build the same game, a round-based arena: you write its first project file after the core modules and ship the finished repository at the end. Every project exercise is built with a faithful in-browser model of Rojo 7.7 so you can see the instance tree your files produce.
