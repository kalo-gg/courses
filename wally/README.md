# Wally

*Package manager for Roblox*

---

Wally replaces copied modules with a manifest: you name what you depend on, and `wally install` resolves the graph into three directories Rojo can sync. This course covers the manifest and the realm rule that catches everyone, what install writes to disk and why its resolver refuses to backtrack, wiring the tree into a place, publishing, and an honest comparison with pesde. You build a game place, then the library it depends on.
