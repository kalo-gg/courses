# Vide

*Fine-grained reactive UI*

---

Vide is a reactive UI library for Luau inspired by Solid: you describe interfaces with `create`, keep state in sources, and let effects keep instances in sync. This course covers creation and components, the reactive graph of sources, derived values, effects and scopes, dynamic UI with show and indexes, actions, springs and context, and how to mount, debug and structure a Vide app. Two projects build one thing, a game HUD: its inventory panel after the third module, then the whole HUD with a health bar, a notification feed and a keyboard toggle at the end.
