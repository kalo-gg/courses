# 1. Vide Foundations

*What a reactive UI library does for you, how to install Vide, and how to build your first elements and components.*

Vide · Easy

---

Roblox UI is usually built by hand: create instances, set properties, connect events, then write more code to keep everything in sync as state changes. Vide flips that around. You describe what the interface should look like for a given state, and it keeps the instances up to date. This module explains the idea, installs Vide 0.4.1, and gets you creating elements and components.

## Lessons

1. [What is Vide?](01-what-is-vide.md) — Declarative, reactive UI for Luau: describe the interface, let the library keep it in sync.
2. [Installing Vide](02-installing-vide.md) — Add Vide 0.4.1 with Wally, pesde or the release rbxm, require it, and read its version.
3. [Creating UI with create](03-creating-ui.md) — Build instances with create, set properties, add children and connect events from one table.
4. [Components and props](04-components.md) — Wrap elements in functions, pass props, and compose small pieces into screens.
