# Blink

*Networking IDL for Roblox*

---

Roblox remotes send Luau tables; Blink sends buffers. You write a file naming your events, functions and types, and the compiler emits a server and a client module that pack every field into the fewest bytes it can. This course covers the type system, events and functions, the options that shape the output, scopes and imports, the Studio plugin and CI, and what each type costs on the wire. You build Crosswire, an arena game's network layer.
