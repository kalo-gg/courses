# Luau Fundamentals

*The language Roblox runs on, from the ground up*

---

Luau is the language every Roblox script is written in, and most people learn it by copying snippets until something works. This course teaches it directly: values and variables, numbers and strings, the three ways to loop, tables as both lists and records, functions and the scope rules that surround them, and finally modules and the errors you will actually hit. Two projects build one thing, a text adventure: the room loop after the fourth module, then the whole game with an inventory, commands and error handling at the end.
