# 2. Numbers, Strings & Booleans

*The three value types you use constantly, the operators that combine them, and what counts as true.*

Luau Fundamentals · Easy

---

Three kinds of value do most of the work in any script: numbers you count with, strings you show, and booleans you decide on. This module covers the arithmetic Luau adds to Lua, the string library and interpolation, the pattern functions that search text, and the rule that decides what counts as true, which is shorter and stranger than most people expect.

## Lessons

1. [Numbers and arithmetic](01-numbers.md) — Every number is a double, and Luau adds floor division, compound assignment and math helpers.
2. [Strings](02-strings.md) — Quotes, escapes, concatenation and interpolation, plus the string functions you reach for daily.
3. [Finding text](03-finding-text.md) — find, match, gsub and gmatch, and the pattern characters that make them worth learning.
4. [True, false and nil](04-truthiness.md) — Only false and nil are falsy, which makes zero and the empty string true and explains and or.
