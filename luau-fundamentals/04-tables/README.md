# 4. Tables

*One data structure does the work of lists, records and everything between. Learn both halves.*

Luau Fundamentals · Medium

---

Luau has one container, and it does two jobs at once. Used with number keys it is a list; used with names it is a record; used with both it is whatever you need. This module covers each half on its own, then nesting, then the table library and the generic for that walks a table you did not count, which is the loop most real code is built from.

## Lessons

1. [Lists](01-arrays.md) — Tables with number keys starting at 1, the length operator, and inserting and removing.
2. [Records](02-dictionaries.md) — String keys, dot against bracket access, and what reading a key that was never set gives you.
3. [Tables inside tables](03-nesting.md) — Rooms with exits, players with inventories: nesting is how real data is shaped, and how it breaks.
4. [The table library and generic for](04-table-library.md) — concat, sort, find, clone and freeze, and the for loop that walks a table you did not count.
