# 1. Luau Foundations

*What Luau is, where it runs, and how to put a value in a variable and see it on screen.*

Luau Fundamentals · Easy

---

Every Roblox script is written in Luau, but most people meet the language sideways, by copying a snippet that nearly does what they want. This module starts at the beginning: what Luau is and how it differs from the Lua it grew out of, what a value is, how a variable holds one, and how to print it and read the error when you get it wrong. By the end you will have written and run a script of your own.

## Lessons

1. [What is Luau?](01-what-is-luau.md) — A gradually typed dialect of Lua built for speed and safety, and the language Roblox runs.
2. [Values and variables](02-values-and-variables.md) — The kinds of value Luau has, how local holds one, and why nil is not the same as zero.
3. [Printing, and reading an error](03-printing-and-errors.md) — print and warn are your output, and a stack traceback tells you which line actually broke.
4. [Your first script](04-first-script.md) — Put values, variables and printing together into a script that greets a named player.
