# 3. Control Flow

*Decisions and repetition: if, while, repeat, numeric for, and the two ways out of a loop.*

Luau Fundamentals · Medium

---

A script that runs top to bottom once can only ever do one thing. Control flow is how it chooses and how it repeats: an if that picks a branch, a while that runs until something changes, a repeat that always runs at least once, and a numeric for that counts for you. Between them these four shapes cover almost every loop you will ever write.

## Lessons

1. [Making a decision](01-if-else.md) — if, elseif and else, the comparison operators, and why one chain beats a staircase of blocks.
2. [Repeating while something is true](02-while-and-repeat.md) — while tests before the body and repeat tests after, so repeat always runs at least once.
3. [Counting loops](03-numeric-for.md) — for i = start, stop, step counts for you, and the loop variable is fresh on every pass.
4. [Leaving a loop early](04-leaving-early.md) — break stops the loop, continue skips the rest of one pass, and nesting decides which one.
