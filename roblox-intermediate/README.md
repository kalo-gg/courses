# Roblox Intermediate

*Client, server and the network between*

---

A Roblox game runs on one server and on one client per player, and each of them has its own copy of the world. This course teaches that split: what replicates, how to write code on the client, how RemoteEvents and RemoteFunctions carry requests across, and why the server must check every one of them. Then it builds what players touch: interfaces on the screen and in the world, input on every device with the Input Action System, tools, the camera, raycasts and spatial queries, pathfinding, and animation and sound. It ends with hiding latency, structuring and testing a multiplayer codebase, and client performance. You build an arena: a loadout system the server validates, then a blaster that runs from key press to server-checked hit.
