# 1. pesde Foundations

*Not a Roblox package manager that happens to run elsewhere — a Luau one that happens to know Roblox.*

pesde · Easy

---

pesde installs Luau packages for whichever runtime you target: standalone Luau, Lune or Roblox. What is pesde? explains why every package declares a target and why the same version can exist four times; Installing pesde gets the binary onto your machine and scaffolds a manifest; Your first dependency adds, installs and requires a package and commits the lockfile; Day to day covers updating, removing by alias and the content-addressable store.

## Lessons

1. [What is pesde?](01-what-is-pesde.md) — Why a Luau package manager declares a target, and where its packages come from.
2. [Installing pesde](02-installing-pesde.md) — Download, self-install, verify and upgrade the binary, then scaffold your first manifest with pesde init.
3. [Your first dependency](03-first-dependency.md) — Add a package, install it, require it, and commit the lockfile that makes the install repeatable.
4. [Day to day](04-day-to-day.md) — Listing, updating, removing by alias, and the content-addressable store under every project.
