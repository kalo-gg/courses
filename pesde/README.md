# pesde

*Packages for Luau*

---

pesde installs Luau packages for standalone Luau, Lune and Roblox — from its own registry, from Wally, from git, or from your own disk. This course covers the manifest and its five dependency specifiers, the extra setup Roblox needs and how it differs from Wally, publishing to a registry that never forgets, the workspace, override, patch, engine and CI features larger projects reach for, and the troubleshooting and migration habits that keep installs boring. Along the way you assemble **Loot**, a weighted drop-table library for Roblox: its manifest and sync config first, then a publishable release with a Studio test place whose built tree is checked.
