# JECS

*Entity Component System for Roblox*

---

JECS is an archetype-based Entity Component System written in pure Luau and inspired by flecs. This course takes you from the ECS mental model through queries, relationships, hooks and signals to Roblox integration and the ecosystem around JECS. Every lesson has a quiz, an activity or a code exercise that runs in your browser, and three projects build the same wave-survival server piece by piece: a headless spawner, then Instances and players, then the whole loop, downloadable as a place file.
