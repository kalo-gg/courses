# 1. ECS Foundations

*What an Entity Component System is, why JECS, how to install it, and your first world.*

JECS · Easy

---

Before writing a line of JECS, you need the mental model. This module explains entities, components and systems, shows why an archetype-based ECS like JECS is a great fit for Roblox games, installs JECS with Wally, the release rbxm or roblox-ts, and ends with your first world: a component, an entity, a value set and read back in the browser sandbox.

## Lessons

1. [What is an ECS?](01-what-is-ecs.md) — Entities, components and systems, and how they differ from Instance scripts and OOP.
2. [Why JECS?](02-why-jecs.md) — Archetype storage, relationships and the features that set JECS apart.
3. [Installing JECS](03-installing-jecs.md) — Wally, the release rbxm and roblox-ts: three ways to get jecs 0.11.0 into a project.
4. [Your first world](04-your-first-world.md) — Create a world, declare a typed component, spawn an entity, set a value and read it back.
