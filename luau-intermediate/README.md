# Luau Intermediate

*Types, metatables and the shape of real code*

---

You can write Luau that works. This course is about writing Luau that keeps working: the type system that catches a mistake before you run it, the table and function types that describe real data, generics for code that is used more than once, metatables and the class pattern they make possible, iterators and closures, and the module boundaries that hold a codebase together. Two projects build one thing, an inventory system: a typed store after the third module, then the whole inventory with classes, iterators and error handling at the end.
